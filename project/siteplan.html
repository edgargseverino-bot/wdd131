Website Planning Document

Site Name

Movie Explorer

Movie Explorer is a movie discovery website that allows users to explore movies by genre, popularity, release year, and other categories.

Site Purpose

Movie Explorer will provide users with an easy way to browse and discover movies. The website will display movie posters, titles, release years, durations, genres, and other movie information. Users will also be able to search for movies and filter them by different categories.

Scenarios

  • How can I find movies from a specific genre?
  • How can I find popular movies to watch?
  • Where can I find information about a specific movie?

Color Schema
